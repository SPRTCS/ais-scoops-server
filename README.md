# Updates für AIS Scoops Server

Dieses Repository enthält nur die veröffentlichten Versionen der Mac-App **AIS Scoops Server**, keinen Quellcode.

- **Neu installieren:** [AIS-Scoops-Server.dmg](https://github.com/SPRTCS/ais-scoops-server/releases/latest/download/AIS-Scoops-Server.dmg) laden, öffnen und die App in „Programme“ ziehen.
- **Aktualisieren:** passiert von selbst. Die App prüft regelmäßig auf neue Versionen, lädt sie im Hintergrund und installiert sie, sobald gerade kein Scoop arbeitet. Danach startet sie neu, der Server läuft gleich wieder.
- Von Hand: in der Menüleiste „Nach Updates suchen …“.

Jede Version ist mit Developer ID signiert und von Apple notarisiert. Die Updates sind zusätzlich digital signiert, die App installiert nur Updates mit gültiger Signatur.
